# Контур — Local AI PC Consultant

Учебный проект по теме «Интеграция ИИ-ассистента в backend-приложение»: локальный консультант по выбору компьютеров и ноутбуков.

## Возможности

- Чат с Qwen 3.5 4B через Ollama, потоковый вывод ответа.
- Каталог из 100 предложений: 50 ноутбуков и 50 готовых компьютеров.
- Подбор по бюджету, карточки товаров со ссылками на источник.
- История диалогов в SQLite, повтор запроса при ошибке.

## Запуск

Нужны Python 3.10+ и работающая Ollama с моделью `qwen3.5:4b`. Сторонние Python-пакеты не требуются.

```powershell
ollama pull qwen3.5:4b
python app.py
```

Откройте http://127.0.0.1:8000. Остановка сервера — Ctrl+C.

Бэкэнд использует стандартный `http.server`, фронтэнд — HTML, CSS и JavaScript без фреймворков. Это локальное учебное приложение, не сервер для публичного размещения.

## Настройки

Переменные окружения:

| Переменная | Значение по умолчанию |
| --- | --- |
| `OLLAMA_URL` | `http://127.0.0.1:11434` |
| `OLLAMA_MODEL` | `qwen3.5:4b` |
| `PORT` | `8000` |
| `APP_DB` | `data/chat.sqlite3` |

Системный промпт и параметры генерации находятся в `app.py`. Файл `.env` автоматически не загружается.

## Каталог и история

`data/catalog.json` содержит готовый каталог предложений «Регарда»: характеристики, цены, ссылки на товары и время загрузки. Независимого архивного подтверждения цен именно на 10.11.2026 нет. Цены и наличие могут изменяться.

Приложение использует готовый каталог без обращения к магазину. Исходные снимки страниц и скрипт сбора удалены из проекта; автоматическое обновление каталога не предусмотрено.

История создаётся автоматически в `data/chat.sqlite3`. База и служебные файлы SQLite исключены из Git через `.gitignore`, чтобы личные диалоги не попадали в репозиторий.

## Проверки

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

Тесты проверяют ограничения бюджета, обработку потокового ответа и фильтрацию текста. Вызовы Ollama в тестах подменены; тесты не оценивают качество реальной модели.
